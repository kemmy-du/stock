# 个股深度分析模板

> 结构化分析规格：供 stock-report 流程生成「深度」报告时逐项填写。
> 主线：**好行业 × 好位置 × 硬技术 × 真投入 × 靠谱的人 × 赢得起 × 买得不贵**。
> 每个维度均标注「字段 / 口径 / 数据来源 / 量化或判断 / 评分锚点」。
> 评分采用 1–5 分制，加权汇总为 0–100 综合分；风险与证伪为**一票否决项**，不计分。

---

## 0. 标的画像（基础信息，不计分）

| 字段 | 口径 | 数据来源 |
|---|---|---|
| 代码 / 名称 / 市场 | CN / US | iFinD `get_stock_info` / `global_stock_profile` |
| 所属行业的 | 申万行业分类 | iFinD 公司资料 |
| 主营业务 | 一句话 + 收入构成占比 | 年报「经营讨论」、公司资料 |
| 上市时间 / 交易所 | — | 公司资料 |
| 当前股价 / 市值 / 评级日期 | 最新交易日 | 行情接口 |

## 1. 行业赛道（权重 15%）

判断「值不值得做」。

| 字段 | 口径 / 单位 | 数据来源 | 量化/判断 |
|---|---|---|---|
| 行业规模 | 当前市场容量（亿元），TAM/SAM/SOM | 行业研报、招股书、协会统计 | 量化 |
| 行业增速 | 未来 3–5 年 CAGR（%） | 研报一致预期 | 半量化 |
| 渗透率阶段 | 当前渗透率（%），爆发期<20% / 饱和期>70% | 研报 | 判断 |
| 生命周期 | 导入 / 成长 / 成熟 / 衰退 | 研报 | 判断 |
| 驱动因素 | 政策 / 技术 / 需求，逐条列 | 政策文件、研报 | 判断 |
| 行业集中度 | CR3 / CR5（%） | 研报 | 量化 |

**评分锚点**
- 5：成长期、CAGR>20%、渗透率<30%、政策顺风
- 3：成熟期、CAGR 5–15%、格局稳定
- 1：衰退期、存量博弈、政策逆风

**结论句式**：「行业规模 __ 亿元，未来 3 年 CAGR __%，处于 __ 阶段，__（顺风/逆风）。」

---

## 2. 竞争位势与市占率（权重 15%）

判断「是不是头部、份额能否持续」。

| 字段 | 口径 / 单位 | 数据来源 | 量化/判断 |
|---|---|---|---|
| 行业排名 | 第几梯队 / 第几名 | 研报、第三方机构（IDC/Counterpoint 等） | 量化 |
| 市占率 | 当前份额（%） | 研报、年报经营讨论 | 量化 |
| 市占率趋势 | 近 3 年份额（升/平/降） | 研报时间序列 | 量化 |
| 与龙头差距 | 份额差 / 收入差 | 计算 | 量化 |
| 定价权 | 毛利率 vs 同行（高/平/低） | 财报同业对比 | 半量化 |
| 份额质量 | 靠技术领先 vs 靠低价/补贴 | 定性 | 判断 |

**评分锚点**
- 5：行业前 2、份额持续提升、毛利率显著高于同行
- 3：第二梯队、份额稳定
- 1：份额下滑、靠价格战换量

**结论句式**：「公司位居行业第 __，市占率 __%（近 3 年 __），份额来自 __，定价权 __。」

## 3. 技术领先度与护城河（权重 25%，核心）

拆成「现在领先」与「能守多久」两层。

### 3a. 技术领先度（现状）

| 字段 | 口径 | 数据来源 | 量化/判断 |
|---|---|---|---|
| 核心性能指标 | 关键硬参数 vs 同行（制程/良率/精度/能效等） | 招股书、行业评测 | 量化 |
| 迭代速度 | 新品发布节奏、研发管线 | 公告、发布会 | 半量化 |
| 发明专利 | 发明专利数量、海外布局、被引（实用新型水分大需剔除） | 专利数据库、年报 | 量化 |
| 行业标准地位 | 是否主导/参与标准制定 | 公开资料 | 判断 |

### 3b. 技术护城河（可持续性，判断为主）

| 字段 | 判断要点 |
|---|---|
| 技术壁垒 | 对手追赶需多久？有无 know-how / 工艺积累 |
| 转换成本 | 客户换供应商的代价（认证周期、迁移成本） |
| 规模/网络效应 | 是否越大越强、生态绑定 |
| 伪护城河排查 | 领先是否仅靠一代产品 / 单一人才 / 补贴 |

**评分锚点**
- 5：性能领先一代以上、壁垒深厚（工艺/生态/转换成本）、对手 3 年内难追赶
- 3：局部领先、有壁垒但可被绕过
- 1：同质化、领先仅靠一代产品或补贴

**结论句式**：「核心技术 __ 领先同行 __，护城河来自 __，预计领先可持续 __ 年；伪护城河风险 __。」

## 4. 研发投入与组织（权重 15%）

判断「领先度的支撑是否真实、可持续」。**必须含近 5 年趋势对比图。**

### 4a. 近 5 年研发趋势（强制）

逐年字段（至少 5 个年度，年度口径，非单季）：

| 字段 | 口径 / 单位 | 数据来源 |
|---|---|---|
| 年度 | YYYY | — |
| 研发费用（费用化） | 亿元 | 年报附注「研发费用」 |
| 研发资本化 | 亿元（开发支出） | 年报附注「开发支出」 |
| 研发占营收比 | %（费用化+资本化 / 营收） | 计算 |
| 资本化率 | %（资本化 / 总研发投入） | 计算 |
| 研发人员数量 | 人 | 年报「员工构成」 |
| 研发人员占比 | %（研发人数 / 总人数） | 计算 |
| 营业收入 | 亿元（算研发强度增速对照） | 财报 |

**图表规格**
- 主图：堆叠柱（费用化 + 资本化，亿元）+ 折线（研发占营收比 %，右轴），横轴 5 个年度
- 副图（可选）：研发人员数量 + 占比近 5 年
- 预警标红：资本化率某年突升（如同比 +10pct 以上）→ 利润美化嫌疑

**关键看点**
- 绝对额是否持续增长（真投入 vs 突击花钱）
- 占营收比是否稳定/上升（强度）
- 研发增速 vs 营收增速（投入是否超前于收入）
- 资本化率是否异常抬升

### 4b. 研发效率与质量

| 字段 | 口径 | 数据来源 |
|---|---|---|
| 人均研发薪酬 | 研发薪酬总额 / 研发人数 | 年报附注 |
| 研发产出 | 新品收入占比 / 专利转化 | 年报、计算 |
| 研发效率 | 研发产出 ÷ 投入 | 计算 |

**评分锚点**
- 5：研发强度>10% 且逐年升、资本化率<10% 稳定、研发人员占比高、产出可验证
- 3：研发强度中等、投入稳定
- 1：研发强度低或资本化率异常高、投入堆砌无产出

**结论句式**：「近 5 年研发投入从 __ 亿增至 __ 亿，强度 __%→__%，资本化率稳定 __%，研发人员占比 __%，投入 __（真实/存疑）。」

## 5. 创始人与治理（权重 10%）

纯定性，长期跟踪。

| 字段 | 判断要点 | 数据来源 |
|---|---|---|
| 创始人背景 | 技术出身 vs 销售/资本出身（决定公司基因） | 简历、访谈 |
| 性格特质 | 专注长期 vs 追风口、务实 vs 画饼 | 访谈、演讲、公开信 |
| 资本配置风格 | 钱投研发/扩产 vs 并购/理财/分红 | 历史资金投向 |
| 诚信记录 | 承诺兑现率、有无减持套现 | 公告、减持记录 |
| 股权激励 | 是否绑定核心技术团队、考核目标 | 激励草案 |
| 股权结构 | 实控人持股、质押率、关联交易 | F10 股东研究 |

**评分锚点**
- 5：技术出身、专注长期、资本配置克制、激励绑定核心、无不良记录
- 3：背景一般但治理规范
- 1：追风口、频繁减持、高质押、关联交易多

**结论句式**：「创始人 __ 出身，风格 __，资本配置偏向 __，治理 __（加分/减分）。」

---

## 6. 财务质量（权重 10%）

判断「赢得起吗」—— 潜力能否兑现。

| 字段 | 口径 | 数据来源 | 预警阈值 |
|---|---|---|---|
| 经营现金流 / 净利润 | 收现比，>1 为佳 | 财报 | 长期<0.8 纸面富贵 |
| ROE / ROIC | %，长期>15% 为佳 | 财报 | ROIC<资本成本 毁价值 |
| 资产负债率 | % | 财报 | 有息负债过高 |
| 应收账款 / 营收 | % | 财报附注 | 突升 |
| 存货周转 | 天数 | 财报 | 恶化 |
| 商誉 / 净资产 | % | 财报 | >30% 减值风险 |

**评分锚点**
- 5：收现比>1、ROE 长期>15%、低杠杆、周转健康
- 3：财务稳健但盈利质量一般
- 1：现金流差、高杠杆、应收/存货恶化

---

## 7. 成长前瞻（权重 5%）

比当期增速更早的先行指标。

| 字段 | 口径 | 数据来源 |
|---|---|---|
| 合同负债 / 预收款 | 亿元，在手订单先行信号 | 财报 |
| 资本开支 + 在建工程 | 亿元，预示未来 1–2 年收入 | 财报 |
| 业绩指引 / 激励考核目标 | 管理层自定增长底线 | 公告、激励草案 |
| 第二增长曲线 | 新业务占比是否起量 | 年报分业务 |

**评分锚点**：5 订单/产能/新业务三者共振向上；1 无任何前瞻支撑。

---

## 8. 商业模式与客户结构（不计分，并入竞争位势/财务质量佐证）

| 字段 | 判断要点 |
|---|---|
| 收入经常性 | 一次性 vs 订阅/耗材/服务占比（高→可持续） |
| 客户集中度 | 前五大客户占比（过高=命脉在外） |
| 客户质量 | 绑定头部大客户 vs 散户 |

---

## 9. 风险与证伪（一票否决项，不计分）

触发任一项 → 综合评级最高「中性」，严重者「减持」。

| 风险类型 | 等级（高/中高/中） | 说明 |
|---|---|---|
| 政策/监管 | | 补贴退坡、反垄断、地缘制裁 |
| 供应链安全 | | 关键原料/设备被卡脖子 |
| 治理 | | 高质押、减持、关联交易、非标审计意见 |
| 颠覆性威胁 | | 跨界对手 / 新技术路线掀桌子 |
| 财务 | | 现金流断裂、商誉暴雷 |

**证伪条件**（出现即重新评估，逐条列）：
- 例：「市占率连续 2 季下滑」「研发资本化率突破 30%」「核心技术人员离职」

**关键跟踪指标**（指标 + 阈值，逐条列）：
- 例：「研发占营收比（≥10%）」「合同负债环比（≥0）」「毛利率（≥__%）」

---

## 10. 估值与情景（权重 5%）

好公司 ≠ 好股票。

| 字段 | 口径 | 数据来源 |
|---|---|---|
| PE(TTM) / PEG / PS / PB | 倍 | 行情、财报 |
| 历史分位 | 当前估值在近 5 年分位（%） | 计算 |
| 同业估值区间 | 可比公司 PB/PE 区间 | 同业对比 |
| 估值倒推 | 当前价隐含的增长假设 | 反推 |

**三档情景**（乐观/基准/悲观，各给假设 + 目标估值 + 空间%）。

**评分锚点**：5 显著低估（历史低分位+低于同业）；1 严重透支。

## 11. 综合评分与结论

### 加权评分表

| 维度 | 权重 | 得分(1–5) | 加权 |
|---|---|---|---|
| 1 行业赛道 | 15% | | |
| 2 竞争位势 | 15% | | |
| 3 技术领先与护城河 | 25% | | |
| 4 研发投入 | 15% | | |
| 5 创始人与治理 | 10% | | |
| 6 财务质量 | 10% | | |
| 7 成长前瞻 | 5% | | |
| 10 估值 | 5% | | |
| **合计** | 100% | | **综合分 = Σ(得分×权重)/5×100** |

> 第 8 商业模式、第 9 风险不单独计分：第 8 并入相关维度佐证，第 9 为一票否决。

### 评级映射（对齐现有 RATING_SET）

| 综合分 | 评级 |
|---|---|
| ≥80 | 买入 |
| 65–79 | 增持 |
| 50–64 | 中性 |
| <50 | 减持 |
| 触发一票否决 | 封顶「中性」，严重直接「减持」 |

### 最终输出

- **cover**：一句话结论（≤40 字）
- **summary**：150–250 字，覆盖「行业/技术/财务/估值」并给明确倾向
- **bull_points / bear_points**：各 3–4 条，每条带具体数字
- **核心矛盾**：一句话点出「最大的上行驱动 vs 最大的下行风险」
