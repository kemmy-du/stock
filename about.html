关于股析

这是什么

股析 StockInsight 是一个纯静态的股票分析报告网站，托管于 GitHub Pages。每份报告由 CodeBuddy 中的 stock-report 技能生成：先通过同花顺 iFinD 数据接口获取行情、财务与新闻资讯，再由 CodeBuddy 内置大模型完成分析并撰写结论，最后以结构化 JSON 落地到本仓库，由前端读取渲染。

报告包含什么

  • 近 60 个交易日日 K 行情与成交量（A股 / 美股）
  • 技术指标：MA5 / MA20 / EMA20 / RSI14 / MACD
  • 财务摘要：营收、净利润、ROE、PE(TTM)、PB
  • 近期新闻公告摘要及情绪标注
  • AI 结论：综合评级、多空要点与逻辑推演

更新方式

当前为手动触发：在 CodeBuddy 中说出「生成 XX 股票分析报告」即可完成取数、分析与发布，网站随之自动更新。后续可接入定时调度实现每日自动更新。

技术栈

  • 纯静态站点：HTML + CSS + 原生 JavaScript，无构建步骤
  • 图表：ECharts（CDN 引入，统一灰色主题）
  • 视觉：依据 web-design 技能的令牌化 CSS 体系，浅灰纸面 + 单一克制强调色
